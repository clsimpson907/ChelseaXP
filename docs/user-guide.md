# ChelseaXP User’s Guide

[Open ChelseaXP](https://chelseaxp.party)

I built ChelseaXP to feel like a computer from 2006. Start with **About Me**, look around the desktop, and try to leave the place roughly as you found it. The phone version uses a Windows Mobile-style Today screen.

## Using the desktop

**About Me** opens when you arrive. Use **Start** in the lower-left corner to open My Documents, My Computer, Control Panel, Help and Support, Search, or Run.

- Click a desktop shortcut once to highlight it. Double-click it, or press **Enter** while it has focus, to open it.
- Drag a window by its title bar to move it. Drag an edge or corner to resize it. The title-bar buttons minimize, maximize or restore, and close the window.
- Click a taskbar button to bring its window forward. Click the active window’s button to minimize it. Each open desktop window has its own button.
- Explorer’s title and icon follow the folder you open. Its taskbar button follows along too.
- When a toolbar runs out of room, its commands move into the **»** menu. Widen the window to bring them back. Explorer’s task sidebar may also hide in a narrow window.

The desktop starts with About Me, LinkedIn, and Recycle Bin. Folders and movable items that you put in Explorer’s Desktop folder appear there during your visit.

## Using a phone

The phone starts on **Today**. Tap **Owner: Chelsea Simpson** to open About Me, or tap **Help and Support** to open the guide.

- Open **Start → Programs** to see the app grid. About Me and Control Panel open from there, and LinkedIn opens the profile.
- Use **Start → Today** to return to the home screen.
- Open **Calendar** from the bottom of Today or from Start. The arrows move between months.
- Today and Calendar use the year **2006**. The clock uses your current local time.
- Open **Start → Run…** to launch a supported program by name.
- Tap **Today** at the bottom of an open app to close it and return home.

File Explorer, Birby’s file search, and Run’s Browse picker are available on desktop. The **No unread messages** row on Today is a placeholder.

## Finding files and folders

Open **Start → My Documents** for Downloads, project notes, and Credits.txt. Open **Start → My Computer** for the virtual drives and common folders.

- Single-click an item to select it. Double-click it to open it.
- With an item selected in the active Explorer window, press **Enter** to open it or **Delete** to request deletion. Text fields, menus, and dialogs handle their own keys.
- Selecting an item in another Explorer window clears the previous selection.
- Switching focus without selecting another item leaves the selection visible in light gray. Bringing its window forward restores the active highlight.
- Use **Back**, **Forward**, and their small history arrows to revisit locations. **Up** opens the parent folder.
- Click a parent name in the Address bar to jump there. Use its dropdown to choose a destination, then select **Go**.
- Use **View** to choose Thumbnails, Tiles, Icons, List, or Details. The dot marks the current layout.
- **Other Places** links to nearby locations. **Details** describes the folder or selected item.

**Local Disk (C:)** initially hides its contents. Select **Show the contents of this drive** to reveal them. The floppy and CD drives ask you to insert a disk. Credits.txt opens in its own Notepad window.

## Searching with Birby

1. Open **Start → Search**. Explorer opens as Search Results with Birby’s Search Companion beside an empty results pane.
2. Choose **Pictures, music, or video**, **Documents**, or **All files and folders**. The search fields appear.
3. Enter all or part of a name and choose **Look in**. Choose media types when using the media search.
4. Select **Search**. Matching items appear in the results pane.

You can also open Search from an Explorer toolbar. **Up** from the initial Start search shows Desktop and keeps Search Companion open. Birby searches ChelseaXP’s virtual files and folders.

## Using Run

Open **Start → Run…**. Type a supported name into **Open**, then choose **OK** or press **Enter**.

On desktop, Run can open a program, folder, or document. For example, **Downloads** opens that folder and **Credits.txt** opens Notepad. A full virtual path can distinguish items with the same name. Choose **Browse…** when you want to pick an item.

The dropdown beside Open lists programs successfully launched through the Run prompt during this visit, most recent first. Opening something from Start, Explorer, or a desktop shortcut does not add it. Folders and documents do not enter that program history.

Run on phones accepts supported programs. Its Browse button and folder navigation are desktop features. Reloading clears the Run history.

## Choosing a file in Browse

1. In Run, choose **Browse…**. The picker opens in My Documents.
2. Use **Look in**, the Places shortcuts, **Back**, or **Up one level** to find the folder you want. On desktop, double-click a folder to enter it.
3. Choose **Files of type**. **Programs** shows executable items and folders for navigation. **All files** also shows documents, portfolio pages, and Internet links.
4. Click a file to fill **File name**, then choose **Open**. The picker closes and Run receives the selected virtual path.
5. Choose **OK** in Run to open the selected item.

The file-name arrow lists matching files in the current folder. You can also type a name. The toolbar includes **Create new folder** where the location permits it and a **View** menu for List, Icons, or Details.

Desktop in Browse uses the same underlying items as the visible desktop and Explorer, with the selected file filter applied. About Me is a portfolio page and LinkedIn is an Internet link, so both appear under All files. Recycle Bin is excluded from Run’s picker. Deleted items must be restored in Explorer before Run can find them.

**My Recent Documents** in this picker shows document entries opened through Run during the visit. **Cancel**, the title-bar X, or Escape closes the picker.

## Making a mess in Explorer

1. Open My Documents or another writable folder and choose **Make a new folder** under **File and Folder Tasks**. A name field appears.
2. Type the name and press **Enter**. The new folder appears in Explorer.
3. Select a folder you made and choose **Rename this folder** to change its name.
4. Choose **Delete this folder**, or press **Delete**, to open a confirmation.

Delete confirmations start with **Yes** selected. **Left Arrow** selects Yes and **Right Arrow** selects No. **Enter** activates the selected button. Choose **No**, press Escape, or use the title-bar X to cancel. The item stays selected, so pressing Delete again reopens the confirmation.

Drag a movable item into another folder to move it. Drop it on Recycle Bin to request deletion. A folder’s contents move or are recycled with it. Protected items can show **Access is denied**.

The virtual desktop, Explorer, Run, and Browse share file and folder data. Creating, renaming, moving, deleting, or restoring an item updates their views. These changes last for the current visit and reset when you reload.

## Using Favorites

Explorer’s Favorites menu starts with My Documents, About Me, and Credits.txt. New built-in items are added to the default list only when Chelsea requests them.

During your visit, drag an eligible item into Favorites to create a shortcut. You can also copy an eligible item and paste it into the Favorites folder. A shortcut whose target was deleted can report a missing target until it is restored.

Explorer Favorites, Help Center Favorites, and Run history each serve their own part of the interface. Reloading resets the visitor’s session changes.

## Using the Recycle Bin

Open **Recycle Bin** on the desktop. Select a deleted item and choose **Restore this item**, or clear the selection and choose **Restore all items**. Choose **Empty the Recycle Bin** and confirm to discard deleted items for the current visit.

Open **Complaints** inside Recycle Bin to read copies that have been reviewed and published. You can read these without signing in. This folder updates quietly in the background. It can appear empty while the service is unavailable.

Restore or empty actions on published complaints briefly hide them from your view. The public copies remain available and can reappear. These actions do not remove published records from the complaints database.

## Playing forkbomb.exe

On desktop, open **My Documents → Downloads → forkbomb.exe**. It starts with one meme window. Each surviving window creates another after a fresh delay between **0.85 and 1.15 seconds**.

- Use a window’s red **X** to close it and stop its spawn timer. Copies it already made keep going.
- **Minimize** puts the window in the restore strip. It continues making copies while minimized.
- **Maximize** fills the ChelseaXP screen. New windows can appear above it. **Restore** returns it to its earlier size.
- Close every window to return to Explorer. If the pile reaches its limit, the ChelseaXP blue screen appears.
- Press a key, click, or tap the blue screen to continue. Escape during the game closes the simulation.

The pop-ups live inside the page. Their count is capped. The operating system has suffered enough.

## Using Control Panel

Open **Control Panel** from Start or the phone’s Programs grid. Use its sidebar to switch between **Category View** and **Classic View**.

Choose **Complaints Department** from either view. To open the Help and Support Center, choose **Help and Support** under **See Also**. Desktop Control Panel also has Explorer-style navigation and folder links.

## Getting help

Open **Help and Support** from Start, or tap its row on Today. Choose a guide topic or search the guide.

Use **Index** to find a topic by keyword. **Favorites** holds guide topics you added during your visit, and **History** lists topics you have read. Open a topic and choose **Add to Favorites** to keep it handy.

Under **Ask for assistance**, choose **Submit a complaint** to open the form. **Complaints Department** is under **Pick a task**.

## Sending a complaint

1. Open Help and Support and choose **Submit a complaint**. ChelseaXP checks whether submissions are available.
2. Enter your email address, subject, and message. Your name is optional. The form accepts a subject up to 120 characters and a message up to 2,000 characters.
3. Select **Send complaint**. A successful response confirms that the complaint was saved for private review.

ChelseaXP attempts to email me a notification after saving the complaint. I’ll use your address if I need to reply. Email notification failure can happen after the complaint has been saved.

The progress bar may lose ground and start filling again during a slow operation. It has a complicated relationship with progress.

| Blue-screen code | Meaning |
| --- | --- |
| `HOURLY_QUOTA_FULL` | You reached your hourly limit. |
| `TEN_MINUTE_QUOTA_FULL` | Visitors collectively reached the rolling ten-minute limit. |
| `DAILY_QUOTA_FULL` | Visitors collectively reached the daily limit. |
| `COMPLAINTS_PAUSED` | Submissions are temporarily disabled. |
| `STATUS_CHECK_FAILED` | ChelseaXP could not check availability. |

Quota messages show a retry time in your local time zone. Defaults are three submissions per visitor per rolling hour, three across all visitors per rolling ten minutes, and ten across all visitors per UTC day.

Press a key, click, or tap a blue screen to continue. A blue screen during the initial availability check closes Complaints. A quota blue screen during submission returns you to your draft.

## Reviewing complaints

The Complaints Department is for Chelsea and invited reviewers. Public submissions and reading published complaints require no reviewer sign-in.

1. Open **Control Panel → Complaints Department**, or use its task link in Help and Support. Sign in with your assigned reviewer account.
2. Select a complaint from the inbox. Its current public copy appears in the reading pane.
3. Select private text in the subject or message, then choose **Redact**. Use **Undo** or **Redo** to revise the redaction.
4. Use **File → Save as draft** to save an unfinished public copy, or **Publish** when it is ready.
5. Choose **Sign out** when you finish.

Admins and moderators can save drafts and publish. The admin can see the submitter’s email and IP address. Both roles can see the submitted name and complaint text. Published copies are locked against further editing in the current review interface.

## Complaint privacy notice

ChelseaXP stores your complaint for private review, including its subject, message, supplied name and email address, submission time, and IP address. The form requires an email address. I use it to reply if needed. Invited moderators can see the submitted name and complaint text. Only the administrator receives email and IP details in the review interface.

ChelseaXP asks Resend to send a notification after saving the complaint. The request includes the subject, message, optional name, submission time, and your email as Reply-To. Your IP address is omitted from the notification.

I or an invited moderator may publish an edited or redacted subject and message in Recycle Bin. The public record omits your name, email, IP address, and private review details.

The server uses your IP address to enforce submission limits. Quota records store a timestamp and a code derived from that address with a secret key. Records older than two days are pruned when a new slot is reserved. Private complaints use a separate record and currently have no automatic deletion schedule.

If you have a question about a complaint you sent, you can reach me through LinkedIn.
